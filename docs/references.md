# References and software attribution

## Core algorithm

- Adams, R. P., & MacKay, D. J. C. (2007). *Bayesian Online Changepoint Detection*. arXiv:0710.3742. [Paper](https://arxiv.org/abs/0710.3742)

The compact BOCPD code in this repository is an independently written,
didactic Beta-Bernoulli reference implementation of the online run-length
recursion. It does not copy code from the projects below.

## Related software

- Kulick, J., & Carisimo, E. (2026). *Bayesian Changepoint Detection: A PyTorch Implementation*. [`hildensia/bayesian_changepoint_detection`](https://github.com/hildensia/bayesian_changepoint_detection).
- Gundersen, G. (2019). *bocd: Python implementation of Bayesian online changepoint detection*. [`gwgundersen/bocd`](https://github.com/gwgundersen/bocd).
- Heins, C. et al. *pymdp: A Python library for active inference in discrete state spaces*. [`infer-actively/pymdp`](https://github.com/infer-actively/pymdp).

## Scientific context

- Behrens, T. E. J., Woolrich, M. W., Walton, M. E., & Rushworth, M. F. S. (2007). Learning the value of information in an uncertain world. *Nature Neuroscience, 10*, 1214–1221. [doi:10.1038/nn1954](https://doi.org/10.1038/nn1954)
- Mathys, C., Daunizeau, J., Friston, K. J., & Stephan, K. E. (2011). A Bayesian foundation for individual learning under uncertainty. *Frontiers in Human Neuroscience, 5*, 39. [doi:10.3389/fnhum.2011.00039](https://doi.org/10.3389/fnhum.2011.00039)

These works motivate the broader question of adaptive learning under uncertainty. They do not provide evidence for any neurocognitive claim made by this synthetic benchmark.
